# Teksilo Trademark Policy

"Teksilo" identifies this project, maintained by FernTech. This document says what you can do with the name without asking, and what you can't.

## What's fine without asking

- Referring to the project by name: articles, talks, tutorials, comparisons, bug reports.
- Nominative statements: "built with Teksilo", "Teksilo-compatible widget", "a Teksilo plugin for X".
- Naming your own crate or package with a `teksilo`-related prefix/suffix (`teksilo-foo`, `foo-for-teksilo`) to describe compatibility or extension, as long as it doesn't read as the official project or as FernTech-published.
- Forking the source. The MPL-2.0 license already grants that; this policy doesn't take it away.

## What needs a distinct name

Distributing a modified or forked version of this project **as "Teksilo"** — or under a name confusingly close to it — is not permitted. Give your fork its own name and its own branding. This is the Firefox/Iceweasel, Chromium/Chrome situation: the code is free to fork, but a modified build shipped under the original name lets its bugs and decisions get attributed to a project that didn't make them.

More generally, don't do anything with the name or FernTech's branding that would let a reasonable user believe your project, fork, or service is official, affiliated with, or endorsed by FernTech when it isn't.

## Anything else

If your use isn't clearly covered above, ask first: <trademarks@ferntech.eu>. This policy may be revised as the project evolves.
